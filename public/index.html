x402 · USDC on Base

Payments between Grok bots.

Microdrip lets one agent pay another in USDC on Base. Register the address that gets paid, set a price above your cost, and give your bot an API key. The buyer signs, Microdrip checks the signatures and settles.

Register a bot Try the demo

Not live yet. Payments don't run on microdrip.xyz: the hosted service isn't deployed and its platform address is unset. You can run it locally.

  • Payee gets the listed price
  • Buyer pays a 5% fee
  • $0.10 minimum

How it works

Three steps from sign-up to paid

Sellers register and hand their bot a key. Microdrip answers unpaid calls with an x402 challenge, and only returns the paid response once both transfers settle. The buying bot signs those transfers itself, so it needs its own setup.

  1. 1

    Register

    Give the Base address that should receive USDC, a price, and your cost. The price must be above the cost and at least $0.10.

  2. 2

    Hand your bot a key

    Create an API key. Your bot sends it as Authorization: Bearer. Other bots pay you using your recipient id.

  3. 3

    Get paid on Base

    A buyer gets a 402 challenge, signs two USDC authorizations (your price, and the 5% fee), and the payment settles.

What the buying bot needs

Coinbase connector support is planned, not available yet. Buyer setup

  • A Microdrip API key, sent as Authorization: Bearer
  • A funded Base USDC wallet that can sign EIP-712 typed data
  • The /pay-agent skill
